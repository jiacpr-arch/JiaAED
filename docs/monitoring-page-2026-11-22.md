# หน้า "ระบบตรวจเครื่อง AED ออนไลน์" — `/aed/monitoring` (22 พ.ย. 2026)

เจ้าของเปลี่ยนจาก landing page ยิงโฆษณา (HeartSave Y8 GPS) เป็นหน้าให้ลูกค้าดูระบบออนไลน์ที่ทีมงานใช้ตรวจเครื่อง
จะได้เข้าใจว่าเครื่องที่เจี่ยรักษาดูแลถูกตรวจอย่างไร — ไม่มีราคา ไม่แยกกลุ่มโฆษณา ไม่มีหน้าฝัง jia1669.com

## เนื้อหา
1. Hero — "เครื่อง AED ของคุณ ถูกตรวจทุกวัน ทีมงานเห็นผลทุกเครื่อง"
2. ขั้นตอน 4 ข้อ: เครื่อง Self-test เอง (ทุก 24 ชม. — ดึงจาก `primedicSharedSpecs`) → ส่งผลเข้า PRIMEDIC CLOUD → ทีมงานเห็นทุกเครื่อง → ติดต่อแก้ไขก่อนถึงวันใช้
3. หน้าจอระบบจริง (เบลอแล้ว — ย่อ 1/16 แล้วเบลอ กู้ข้อความไม่ได้) + ตัวเลข 19 / Normal 15 / Alert 4 ป้าย "ภาพ ณ 23 พฤศจิกายน 2569 · ไม่ใช่ข้อมูลสด"
4. ข้อมูลที่ระบบเห็นรายเครื่อง + หมายเหตุว่าลูกค้าเข้าดู Dashboard เองได้เฉพาะ ELITE
5. แอปมือถือ myAED Finder — ค้นหาเครื่องใกล้สุด นำทาง เวลาเข้าถึง ปุ่มโทร 1669 (ข้อความจากภาพแอปที่เจ้าของส่ง)
6. ติดต่อ: LINE, โทร, ฟอร์ม "ขอให้ทีมงานพาดูระบบ" (`aed_leads.source = monitoring_form`)

ลิงก์เข้าหน้านี้: footer ทุกหน้า (ระบบตรวจเครื่องออนไลน์) และส่วน Cloud Dashboard ใน `/aed/subscription` · อยู่ใน sitemap

**ไม่ใช้:** Rescue History (SN + เหตุใช้ช่วยชีวิตจริง — คำกล่าวอ้างทางการแพทย์ที่อ่อนไหว) · Customer list (ชื่อ อีเมล เบอร์ของบุคคล)
**รอไฟล์:** ภาพแอป myAED Finder 2 ภาพ (หน้าแรก + รายการ AEDs) — ต้องปิด Device SN และจุดฟ้าตำแหน่งของผู้ใช้มือถือ
เก็บไว้เฉพาะจุดติดตั้งที่ตั้งใจเปิดสาธารณะ (JIA TRAINER CENTER) จุดอื่นปิด แล้วใส่ใน `APP_SCREENSHOTS`
**รอไฟล์ด้วย:** ตาราง Device details (%แบต อุณหภูมิ แรงดัน Self-test) — ต้องปิด Device SN + Battery SN ทุกแถวและเบอร์บัญชี

ทำซ้ำ: `node scripts/redact-image.mjs <ต้นฉบับ> public/images/<ชื่อ>-redacted.png <boxes.json>` (รองรับ `crop`)
ห้าม commit ต้นฉบับ · test บังคับไฟล์ต้องลงท้าย `-redacted.png`, ขนาดตรง, ไม่มี EXIF/XMP · ห้ามใช้ `/images/cloud-dashboard.png` (ภาพประกอบ ตัวเลขไม่จริง)

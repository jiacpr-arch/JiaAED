## ซื้อออนไลน์
- ขายเฉพาะ 1 เครื่อง รุ่นที่ลิสต์บนเว็บ (Y2, Y0) — ราคาเว็บ + VAT 7% (Y2 = ฿53,393, Y0 = ฿42,798.93)
- หลายเครื่อง / ภาครัฐ / เช่าซื้อ / GPS → ใบเสนอราคาทาง LINE เหมือนเดิม
- ปุ่ม "ซื้อออนไลน์" → `/api/checkout` → หน้า Stripe (บัตร + PromptPay, เก็บที่อยู่จัดส่ง, เบอร์, เลขผู้เสียภาษี/ชื่อบริษัท/สาขา)
- จ่ายแล้ว → `/api/stripe/webhook` บันทึก `aed_orders` + แจ้ง LINE แอดมิน → ลูกค้าเห็นหน้า `/aed/checkout/success`

## หมายเหตุ: บัญชี Stripe ใช้ร่วมกับเว็บอื่น (Jia1669)
- endpoint `jiaaed-payments` ได้รับ event ของทุกเว็บในบัญชี (Morroo, Roodee, PharmRoo …)
- webhook รับเฉพาะ checkout ที่มี product_id ในแคตตาล็อกของเว็บนี้ · ตัดบัตรรายเดือน/กันวงเงินกรองด้วย metadata.kind — event ของเว็บอื่นถูกข้าม (ตอบ 200)
- ปลายทางเก่า "JiaAED production webhook" (jiaaed.vercel.app) ให้ลบ — ใช้ secret คนละตัว จะ fail ทุกครั้ง

## ขั้นตอนเปิดใช้ (เจ้าของ)
1. Supabase SQL Editor: รัน `supabase/aed_orders.sql` และ `supabase/aed_rental_billing.sql`
2. Stripe Dashboard → Settings → Payment methods: เปิด **PromptPay** (และ Cards)
3. Stripe → Developers → Webhooks: แก้ endpoint เดิม `https://www.jiaaed.com/api/stripe/webhook`
   ให้ฟัง `checkout.session.completed`, `checkout.session.async_payment_succeeded`, `checkout.session.async_payment_failed`,
   `invoice.paid`, `invoice.payment_failed`, `customer.subscription.deleted`, `payment_intent.canceled` → คัดลอก Signing secret
   (เวอร์ชัน API ของ endpoint จะเป็น 2022-11-15 หรือใหม่กว่าก็ได้ — โค้ดอ่านได้ทั้งสองแบบ)
4. Vercel env: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` (ทดสอบด้วย `sk_test_…` ก่อน แล้วค่อยเปลี่ยนเป็น live) → redeploy
5. (ไม่บังคับ) `STRIPE_PAYMENT_METHODS=promptpay` ถ้าไม่รับบัตร · `CHECKOUT_DISABLED=1` เพื่อซ่อนปุ่มชั่วคราว
6. Stripe → Settings → Customer emails: เปิด "Successful payments" ให้ลูกค้าได้ใบเสร็จอัตโนมัติ

ยังไม่ตั้ง `STRIPE_SECRET_KEY` = ปุ่มซื้อออนไลน์ไม่แสดง เว็บทำงานเหมือนเดิม (แต่ราคาเดิมขีดฆ่าของ Y2 แสดงทันที)

| FLEX (บุคคล / นิติบุคคล) | เงินประกัน ฿10,000 / ฿7,000 (ไม่มี VAT) + เดือนแรก ฿3,199.30 | ฿3,199.30 | ทีมยกเลิกใน Stripe เมื่อคืนเครื่อง |

- เลือกจำนวนเครื่องได้ 1–20 · ลิงก์ใช้ได้ 23 ชม. (ข้อจำกัด Stripe) — หมดอายุก็สร้างใหม่
- แจ้ง LINE แอดมินทุกงวด: ตัดผ่าน (ออกใบกำกับภาษี) / ตัดไม่ผ่าน (พร้อมลิงก์ให้ลูกค้าจ่าย/เปลี่ยนบัตร) / ผ่อนครบ (โอนกรรมสิทธิ์) / ถูกยกเลิก
- ตั้งใน Stripe → Settings → Billing → Revenue recovery: Smart Retries + ส่งอีเมลลูกค้าเมื่อตัดไม่ผ่าน / บัตรใกล้หมดอายุ
- คืนเงินประกัน FLEX: Stripe → ใบแจ้งหนี้แรกของลูกค้า → Refund เฉพาะยอดเงินประกัน
- ใบกำกับภาษียังออกจาก FlowAccount ตามเดิม (Stripe ส่งใบเสร็จทางอีเมลอย่างเดียว)

## เปลี่ยนเช่า → ซื้อ / เช่าซื้อ (หักมัดจำ) — แท็บ "เปลี่ยนเช่า → ซื้อ"
- เลือกลูกค้า FLEX (หรือกด "เปลี่ยนเป็นซื้อ" ในตาราง) → เลือก ซื้อ Y2 / Y0 หรือเช่าซื้อ Y2 / GPS
- เงินประกันหักได้ไม่เกินที่ลูกค้าวางไว้ · ค่าเช่าที่จ่ายแล้วจะหักด้วยหรือไม่ = โปร ทีมใส่ตัวเลขเอง (0 = ไม่หัก)
- VAT คิดจากราคาเต็ม แล้วหักเครดิตจากยอดรวม: ซื้อ Y2 = 53,393 − 10,000 = **43,393**
- เช่าซื้อ: หักจากเงินดาวน์ ค่างวดรายเดือนเท่าเดิม · เครดิตเกินเงินดาวน์ ระบบแจ้งยอดที่เหลือให้ทีมจัดการเอง
- ลูกค้าจ่ายแล้ว → ระบบหยุดตัดค่าเช่า FLEX เดิมเอง (ไม่คืนเงินประกัน) + LINE แจ้งทีม
- บัญชี: ใบกำกับภาษีออกเต็มราคา บันทึกเงินประกัน/ค่าเช่าที่หักเป็นรับชำระ (ยืนยันกับฝ่ายบัญชี)

## กันวงเงินบัตร — เช่าอีเวนต์ (แท็บ "กันวงเงินเช่าอีเวนต์")
- ลิงก์ให้ลูกค้ากันวงเงิน = ค่าเช่า (รวม VAT) + มัดจำ ฿30,000/เครื่อง — **ยังไม่ตัดเงิน**
- คืนเครื่อง → กด "เก็บค่าเช่า" ใส่ค่าเสียหาย (ถ้ามี) → ตัดเฉพาะยอดนั้น ที่เหลือปล่อยคืนบัตรอัตโนมัติ · งานยกเลิก → กด "ยกเลิก" ปล่อยทั้งหมด
- วงเงินบัตรอยู่ได้ประมาณ 7 วัน → ใช้ได้เฉพาะเช่าที่คืนเครื่องภายใน 6 วัน (รายวัน 1–6 วัน / สุดสัปดาห์) · เช่า 7 วันขึ้นไปใช้มัดจำเงินสดเหมือนเดิม
- LINE เตือน 09:00 และ 16:00 น. เมื่อวงเงินจะหมดอายุภายใน 36 ชม. · ถ้าหมดอายุก่อนกดเก็บ = เก็บค่าเช่าไม่ได้ ต้องส่งลิงก์ชำระใหม่ (LINE แจ้ง)
- กันวงเงิน 30 วันได้ถ้าเปลี่ยนเป็นแผนราคา IC+ ของ Stripe (ติดต่อ Stripe) — ตอนนี้ยังไม่ใช้

## คืนเงินจากหน้า admin (`/admin/billing`)
- **ออเดอร์ซื้อออนไลน์:** ตาราง "ออเดอร์ซื้อออนไลน์" → ปุ่ม "คืนเงิน" → ใส่ยอด (คืนเต็มหรือบางส่วน ไม่เกินยอดที่จ่าย) → LINE แจ้ง · ออกใบลดหนี้ใน FlowAccount
- **จบเช่า FLEX:** แถวลูกค้า FLEX → "จบเช่า + คืนเงินประกัน" → ใส่ค่าเสียหาย (0 ถ้าครบสภาพ) → หยุดตัดค่าเช่า + คืนเงินประกันส่วนที่เหลือเข้าบัตรเดิม → LINE แจ้ง
- เงินเข้าบัตรลูกค้าใน 5–10 วันทำการ · **Stripe ไม่คืนค่าธรรมเนียม** ของยอดที่คืน
- เช่าซื้อไม่มีปุ่มคืนเงิน (ดาวน์/ค่างวดไม่คืนตามสัญญา) · กันวงเงินใช้ปุ่ม "ยกเลิก"/"เก็บค่าเช่า" เดิม (ไม่ต้องคืนเงิน)

## คืนเครื่องช้า (กันวงเงินเช่าอีเวนต์)
- ค่าคืนช้า ฿900/วัน + VAT (ตามข้อ 7.1) — หน้า admin คำนวณจากวันคืนเครื่องให้อัตโนมัติ แถวที่เลยกำหนดขึ้นสีแดง
- **คืนช้าแต่วงเงินยังไม่หมด:** กด "เก็บค่าเช่า" → ระบบใส่ค่าคืนช้าให้แล้ว (บวกค่าเสียหายได้) → ตัดเฉพาะยอดนั้น ที่เหลือปล่อยคืน
- **ยังไม่ได้เครื่องคืน แต่วงเงินใกล้หมด (LINE เตือน):** กด "เก็บค่าเช่า" → พิมพ์ `all` → เก็บเต็มวงเงินไว้ก่อน
  - ได้เครื่องคืนแล้ว → ปุ่ม "คืนเงินส่วนเกิน" → ใส่ยอดที่ร้านเก็บไว้ (ค่าเช่า + คืนช้า + ค่าเสียหาย ระบบใส่ให้) → ระบบหัก **ค่าธรรมเนียมบัตรจริงจาก Stripe ของส่วนที่คืน** (Stripe ไม่คืนค่าธรรมเนียม) แล้วคืนที่เหลือ
  - เงื่อนไขนี้เขียนไว้ในสัญญาเช่า ข้อ 3.3 (หน้า /aed/rental/terms)

## เพดานจำนวนเครื่องต่อลูกค้า (เช่าซื้อ + FLEX)
ทุนเครื่อง ~฿25–30k แต่ดาวน์/เงินประกันครอบคลุมแค่บางส่วน → จำกัดตอนสร้างลิงก์ (`lib/aed/credit-limits.ts`)

| ลูกค้า | เพดาน |
|---|---|
| บุคคลธรรมดา / ร้านค้าเล็ก | 1 เครื่องรวมทุกสัญญา |
| นิติบุคคล (เช็ค DBD แล้ว) รายใหม่ | 2 เครื่องรวม |
| นิติบุคคลที่จ่ายแล้ว ≥ 3 งวด | เพิ่มได้ทีละ 2 เครื่องต่อลิงก์ |
| มีงวดค้างชำระ | สร้างลิงก์ใหม่ไม่ได้ |

- นับลูกค้าเดียวกันจาก ชื่อบริษัท / อีเมล / เบอร์โทร (ตัดคำว่า บริษัท/จำกัด/Co.,Ltd. ออกก่อนเทียบ)
- เกินเพดาน → หน้า admin ถามว่าจะอนุมัติไหม + ให้ใส่เหตุผล → LINE แจ้งแอดมินพร้อมเหตุผล
- ไม่นับ: กันวงเงินเช่าอีเวนต์ (วงเงินครอบคลุมเครื่อง) และการซื้อขาด (จ่ายเต็ม)

## ติดตามออเดอร์หลังชำระเงิน (แท็บ "ออเดอร์ออนไลน์")
- ทุกออเดอร์ที่จ่ายแล้วเดิน 4 ขั้น: **ใหม่ → โทรยืนยันแล้ว → ส่ง/ติดตั้งแล้ว → ออกใบกำกับแล้ว** กดปุ่มทีละขั้น ระบบแจ้ง LINE ทุกแอดมินทุกครั้งที่อัปเดต
- ขั้น "ส่ง/ติดตั้งแล้ว" ใส่เลขเครื่อง + วันหมดอายุแผ่น/แบต → ระบบบันทึกเข้า `aed_units` (สถานะ "ขายแล้ว") แล้วรายงานแผ่น/แบตทุกวันจันทร์จะครอบคลุมเครื่องนี้เอง
- Cron `/api/cron/order-followups` ทุกวัน 09:17 น. ส่ง LINE (+ อีเมลสำรองถึงเจ้าของ) เมื่อ
  - ออเดอร์ค้างขั้นเดิมเกิน 24 ชม.
  - ครบ 7 วันหลังส่ง → โทรถามการใช้งาน + ชวนอบรม CPR ฟรี
  - ครบ 11 เดือนหลังส่ง → ชวนต่อบริการดูแลรายปี + เช็กแผ่น/แบต
  กด "✓ โทรแล้ว" เพื่อปิดรายการ งานค้างแสดงในหน้าแรก /admin ด้วย
- ลูกค้าได้อีเมล "ได้รับคำสั่งซื้อแล้ว" อัตโนมัติ 1 ฉบับ (ต้องมี RESEND_API_KEY) — การติดตามหลังขายให้ทีมโทร/ทักเอง ระบบไม่ส่งหาลูกค้าอัตโนมัติ
- ผู้รับแจ้งเตือน LINE: `AED_OWNER_LINE_USER_ID` + `AED_ADMIN_LINE_USER_IDS` (คั่นด้วยจุลภาค) · อีเมลสำรอง: `AED_OWNER_NOTIFY_EMAILS`
